## Pro 5× 和 20× 怎么选

| 对比项 | Pro 5× | Pro 20× |
|---|---|---|
| 官方美元月价 | $100 / 月 | $200 / 月 |
| Work / Codex 标称用量 | 相对 Plus 的 5× 档 | 相对 Plus 的 20× 档 |
| 较适合的需求 | 持续工作，任务之间有间歇 | 5× 已反复触顶，后续工作仍密集 |
| 需要权衡 | 总支出较低，仍要安排用量 | 使用余量更大，总支出更高 |

两档主要区别是用量，个别模型和功能仍可能有不同限制。5× / 20× 不代表固定消息数、工作时长或结果质量倍数。模型、上下文、推理强度、工具使用和缓存都会影响消耗；Work 与 Codex 共享用量。[官方套餐与用量](https://learn.chatgpt.com/docs/pricing)。

我会用这几个问题判断：

- 常用模型是否满足任务要求，是否真的需要 Pro 提供的功能或更多用量？
- 过去是否经常在重置前用完？接下来还会持续高强度使用，还是只剩一个短期项目？
- 多买的余量能否用到，总支出是否在预算内？
- 当前已有订阅的话，换档费用与剩余时长怎么处理？

拿不准自己的使用强度时，可以填写 [用量记录表](./articles/pro-usage-journal.md#journal)，把任务是否完成、是否被限额打断和后续工作一起看。

20× 的标称用量是 5× 的 4 倍，但不能把比例换算成保证完成多少任务。比较价格时，还要考虑总支出和已有订阅，不只比较单位额度。

## Astra 发布后，Pro 用户要注意什么

GPT-6 Astra 已发布，面向代码、应用和研究中的复杂多步骤工作。可用性仍受开放进度、登录方式、客户端和工作区权限影响；看到发布消息，不代表所有账号和界面同时开放。[Astra 更新说明](https://learn.chatgpt.com/docs/whats-new)、[模型与可用性](https://learn.chatgpt.com/docs/models)。

在 Work / Codex 中，Pro 5× / 20× 提供更大的使用空间。Plus 的用量说明也列有 Astra，不能把它写成只有 Pro 才能使用；普通 Chat 的入口与限额则应单独核对。已有 Pro 用户先查看模型选择器和 Usage，无需因为新模型名称再买一次订阅。

- **持续做复杂任务**：把材料、约束和验收要求准备好，再用实际任务评估效果与消耗。
- **只缺模型入口**：先核对账号和客户端；公司工作区再联系管理员确认权限。
- **额度到顶**：看重置时间、剩余额度及可选方案，不要把重新充值视为保证重置。
- **结果不符合预期**：检查任务范围和材料，必要时拆分任务并人工复核；更高用量不保证结果正确。

展开说明见 [GPT-6 Astra 发布后，Plus 和 Pro 怎么选](https://github.com/duck-gogo/chatgpt-plus-tutorial/blob/main/articles/gpt-6-astra-which-plan.md)。

## 已有 Plus / Pro，先核对换档影响

先记录当前套餐、到期时间和 [Usage](https://chatgpt.com/codex/settings/usage)，再确认自己是在变更官方订阅，还是购买第三方商品。

| 购买方式 | 需要核对 |
|---|---|
| OpenAI 账号内变更订阅 | 以官方确认页的费用、生效时间和账单周期为准 |
| PlusGO Pro 5× 改为 20× | 当前不能补差价升级，需要按 20× 全价重新购买 |
| PlusGO 覆盖已有订阅 | 新套餐重新计算 1 个月，不叠加原订阅剩余时间 |
| 覆盖后的 Codex 用量 | 可能只补足新旧套餐差额，也可能重置，以账号显示为准 |

**不要按“先买 5× 试试，不够再补差价”的预期购买 PlusGO 的 Pro。** 已经有 Plus、5× 或其他有效订阅时，先在购买页确认账号是否适用、完整费用和覆盖影响；不清楚就先联系客服。

这些第三方条件不替代 OpenAI 官方订阅规则。已有自动续费的订阅，也要到原购买渠道核对后续扣款安排。

逐项填写 [换档与续费清单](./articles/pro-upgrade-renewal-checklist.md)，可以在付款前留下费用、账期与覆盖影响的确认记录。

## 公司统一采购 Pro 与报销

公司可以为员工分别采购个人 Plus、Pro 5× 或 Pro 20×，不必统一买最高档。需要统一工作区、成员管理和团队数据政策时，再比较 Business。

我会在付款前准备：

1. 各档套餐的账号数量、使用周期和期望开通时间；
2. 当前订阅情况，以及需要新开通还是续费；
3. 报价、预算、合同和付款主体要求；
4. 发票票种、抬头、税号、开票内容与财务所需材料；
5. 交付验收、异常联系和后续续费安排。

PlusGO 的企业采购可沟通报价、合同、对公付款与发票，具体范围按双方确认的方案执行。个人 Pro 批量采购数量需单独确认，不能套用 Business 席位起购数。公司出钱购买个人 Pro，不会自动获得 Business 或 Enterprise 的组织功能。

完整清单和采购入口见 [公司统一采购 Plus / Pro / Business](https://github.com/duck-gogo/chatgpt-plus-tutorial/blob/main/articles/chatgpt-enterprise-procurement.md)；员工垫付后的凭证准备，见 [Pro 公司报销指南](https://github.com/duck-gogo/chatgpt-plus-tutorial/blob/main/articles/chatgpt-pro-company-reimbursement.md)。

## 订阅方式与支付失败

### 账号内直接订阅

所在地、付款方式和发卡地区符合支持条件时，可以在自己的 ChatGPT 账号内查看升级方案，按真实账单信息付款。价格、币种、额外验证与续费安排以结账页为准；如果 App 内显示所需 Pro 档位，也要核对该渠道的订阅管理方式。

卡片被拒时，先检查是否实际扣款、账单信息和银行验证，保留原始提示并联系对应支持方。不要连续重复付款，也不要填写虚假地区或账单地址。

### 支持支付宝 / 微信的第三方服务

第三方服务可作为付款方式的备选，但会增加服务主体、凭证处理和交付条款风险。付款前确认商品开到自己的账号、档位和有效期正确、订单可查询，以及失败和已交付后的处理规则。

不要购买共享或来源不明的账号，不要交出 ChatGPT 密码、邮箱密码或验证码。临时会话凭证虽然不是密码，仍可能允许访问账号；需要提交时，先确认域名、订单、用途和保存方式，不能理解成“不要密码就没有风险”。

地区、付款和账号规则的进一步检查，见 [主教程的付款方式与风险说明](https://github.com/duck-gogo/chatgpt-plus-tutorial#summary)。

## 开通与验收步骤

1. **核对账号**：记录当前套餐和有效期，已有订阅先确认覆盖条件。
2. **确认商品**：区分 Pro 5× 与 20×，核对完整费用、周期、付款和售后条款。
3. **完成付款**：按页面提示支付，保存订单号和付款记录；结果不确定时先查询原订单。
4. **确认目标账号**：按订单要求提交必要信息，核对显示的账号无误后再确认。
5. **等待原订单结果**：按预计时间查询，超过说明时间仍无变化时凭订单联系售后，不重复购买。
6. **验收订阅与用量**：分别核对目标套餐、到期时间和 Usage；模型入口缺失再按 Astra 小节排查。

套餐、模型入口和用量出现不一致时，按 [开通后排查步骤](./troubleshooting/pro-access-and-usage.md) 分别检查，不要直接重复购买。

## 第三方服务自检

我会优先看能否在付款前说清套餐、账号要求、费用和售后，而不是只看便宜或到账截图。

出现以下情况时，先停止提交信息或付款：

- 要求账号密码、邮箱密码或验证码；
- 收款主体、域名或订单查询方式无法核对；
- 未说明临时会话凭证的用途与处理方式；
- 没有写清覆盖、未交付、失败和已交付后的退款边界；
- 承诺账号不会被限制、模型全部立即开放或任何任务都不限量。

## 常见问题

### 没买过 Plus，可以直接买 Pro 吗？

可以直接比较 Pro。先确认真实需求、账号资格、支持地区和付款条件；无需为了满足不存在的前置步骤先买 Plus。轻量使用者仍可选择 Plus。

### Pro 20× 是不是不限量？

更高的使用档位仍可能遇到模型、功能或周期上限，不能理解成 Work / Codex 任务不限量。以 Usage 和实际功能提示为准。

### 5× 买完不够用，能补差价吗？

通过 PlusGO 购买时，当前不能补差价升级到 20×，需要按 20× 全价重新购买，并确认覆盖后的周期。官方订阅变更则单独看 OpenAI 账号里的确认页。

### 买 Pro 能马上看到 Astra 吗？

不能仅凭购买承诺。入口受账号、客户端、开放进度和工作区设置影响；订阅正常但未看到模型时，先核对这些条件。

### 微信支付和支付宝能直接在 ChatGPT 里用吗？

官方可用付款方式以实际结账页为准。第三方商品展示的支付宝 / 微信入口，不等于 OpenAI 官网支持相同付款方式。

### 付款后没生效或失败怎么办？

保存订单号、付款记录、时间和脱敏的订阅状态截图，查询原订单并联系对应购买渠道的售后。不要反复下单，也不要在公开 Issue 中提交账号、手机号、订单或会话凭据。

### 公司多人使用 Pro，可以统一付款吗？

可以沟通个人账号统一采购；套餐数量、合同、对公付款与发票安排需在付款前确认。每位员工使用自己的账号，需要组织管理时再比较 Business。

## 最后建议

先判断任务和用量，再核对费用、账号与换档条件。需求明确的重度用户可以直接比较 Pro；公司付款的先完成采购确认。开通后分别检查订阅有效期、可用模型和 Usage，才能确认自己得到的是需要的方案。

产品、价格、额度和第三方条款都可能变化，以账号、结账页及本次采购约定为准。
