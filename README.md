## Astra 发布后，Pro 用户要注意什么

GPT-6 Astra 已发布，面向代码、应用和研究中的复杂多步骤工作。可用性仍受开放进度、登录方式、客户端和工作区权限影响；看到发布消息，不代表所有账号和界面同时开放。[Astra 更新说明](https://learn.chatgpt.com/docs/whats-new)、[模型与可用性](https://learn.chatgpt.com/docs/models)。

现在需要分清两个入口：**普通 Chat 的 GPT-6 Pro 由 Astra 驱动，Pro 三档均包含；Plus 包含的是 Work / Codex 中的 Astra，不包含普通 Chat 的 GPT-6 Pro。** Business、Enterprise 的访问还需核对工作区权限。[官方模型与套餐说明](https://help.openai.com/en/articles/20001354-gpt-6-and-other-models-in-chatgpt)。

普通 Chat 的限额也不等于 Work / Codex 的用量倍数：

| 当前个人 Pro 档位 | 普通 Chat 中需留意的关系 | 如何核对 |
|---|---|---|
| Pro 100 | GPT-6 Pro 与 GPT-5.6 Sol Pro 共享每周额度 | 查看模型提示与重置时间，切换不另送一份 |
| Pro 200 | GPT-6 Pro 周额度、Sol Pro 日额度与两模型合计日额度分别受限 | GPT-6 Pro 周额度耗尽可回退到 GPT-5.6 Thinking Medium；另看 Sol Pro 是否仍可用 |
| Pro 500 | 仍有模型及功能限制 | 按账号提示查看，不按其他档位的旧次数外推 |

当前官方页面已不列旧版每周 50 / 200、每日 170 条为固定承诺，本指南不再据此推算新额度。普通 Chat 看模型提示；Work 与 Codex 共享另一套用量，查看 [Usage](https://chatgpt.com/codex/settings/usage)。达到模型限额不等于订阅失效，不要靠重新充值或购买 Codex 点数保证恢复 Chat 额度。

**当前模型入口：** 10 月 7 日起 GPT-6 逐步进入普通 Chat；付费档位按账号权限使用 GPT-6 Sol 的推理选项，Pro 选项由 Astra 驱动。选择 Latest 会转到新模型，明确选定 GPT-5.6 Sol 的旧对话仍使用 5.6。**GPT-6.1 Sol 是 Work / Codex 的更新，不能直接当成普通 Chat 的同名权益**；具体以客户端模型选择器为准。[模型说明](https://help.openai.com/en/articles/20001354-gpt-6-and-other-models-in-chatgpt) · [更新记录](https://help.openai.com/en/articles/6825453-chatgpt-release-notes)。

- **持续做复杂任务**：把材料、约束和验收要求准备好，再用实际任务评估效果与消耗。
- **只缺模型入口**：桌面端手动打开 `Menu → Check for Updates`；Codex CLI 使用 Astra 至少需要 `0.153.0`。公司工作区再联系管理员确认权限。
- **额度到顶**：看重置时间、剩余额度及可选方案，不要把重新充值视为保证重置。
- **结果不符合预期**：检查任务范围和材料，必要时拆分任务并人工复核；更高用量不保证结果正确。

展开说明见 [GPT-6 Astra 发布后，Plus 和 Pro 怎么选](https://github.com/duck-gogo/chatgpt-plus-tutorial/blob/main/articles/gpt-6-astra-which-plan.md)。

### Pro 专属输入预测 Beta：少打字，不是自动执行

Codex 桌面端的 Composer predictions 面向 **18 岁及以上的个人 ChatGPT Pro 用户**，覆盖受支持地区。使用最新桌面端、本地或 SSH 对话，以及 GPT-6 Astra / GPT-6.1 Sol；普通 Chat 网页或桌面聊天不适用。

回复后可能出现下一条消息建议，不保证每次出现。按 `Tab` 接受后仍应检查、修改，再自行发送；它不会自动发消息或继续任务。默认开启，可在 `Settings → General → Composer → Show predictions` 关闭。

**Beta 期间生成建议不另收费，也不消耗 Codex 用量或点数；真正发送的消息仍按正常规则计量。** 不要把它理解成免费无限执行或无人值守编码。[官方输入预测说明](https://help.openai.com/en/articles/20001601-composer-predictions-in-codex)。

## 订阅方式与支付失败

### 账号内直接订阅

所在地、付款方式和发卡地区符合支持条件时，可以在自己的 ChatGPT 账号内查看升级方案，按真实账单信息付款。价格、币种、额外验证与续费安排以结账页为准；如果 App 内显示所需 Pro 档位，也要核对该渠道的订阅管理方式。

卡片被拒时，先检查是否实际扣款、账单信息和银行验证，保留原始提示并联系对应支持方。不要连续重复付款，也不要填写虚假地区或账单地址。

### 支持支付宝 / 微信的第三方服务

第三方服务可作为付款方式的备选，但会增加服务主体、凭证处理和交付条款风险。付款前确认商品开到自己的账号、档位和有效期正确、订单可查询，以及失败和已交付后的处理规则。

不要购买共享或来源不明的账号，不要交出 ChatGPT 密码、邮箱密码或验证码。临时会话凭证虽然不是密码，仍可能允许访问账号；需要提交时，先确认域名、订单、用途和保存方式，不能理解成“不要密码就没有风险”。

地区、付款和账号规则的进一步检查，见 [主教程的付款方式与风险说明](https://github.com/duck-gogo/chatgpt-plus-tutorial#summary)。

## 开通与验收步骤

以下以 PlusGO 第三方购买流程为例。直接向 OpenAI 或应用商店订阅的用户，沿用原渠道流程；购买第三方服务不能延长官方旧额度截止日。

1. **核对账号**：记录当前套餐和有效期，按购买页确认条件；如要求核验，先完成并确认账号再付款。
2. **确认商品**：当前 Pro 100 / 200 在售，Pro 500 暂停，旧续订商品隐藏；核对完整费用、周期、覆盖与售后，不将原 20× 名称当成新购额度。
3. **完成付款**：按页面提示支付，保存订单号和付款记录；结果不确定时先查询原订单。
4. **确认目标账号**：支付后仍需回原订单核对目标账号并明确确认提交；需更新 Session 时只用该订单提供的入口，按实际提示核验、确认。覆盖影响应在付款及确认开通前读清。
5. **等待原订单结果**：按预计时间查询，超过说明时间仍无变化时凭订单联系售后，不重复购买。
6. **验收订阅与用量**：核对套餐和有效期；历史续订按原约定区分安排完成与扣费后的新周期。Usage、Chat 模型限额及入口另外检查，不保证额度全满或继续保留旧 20×。

套餐、模型入口和用量出现不一致时，按 [开通后排查步骤](./troubleshooting/pro-access-and-usage.md) 分别检查，不要直接重复购买。

## 第三方服务自检

我会优先看能否在付款前说清套餐、账号要求、费用和售后，而不是只看便宜或到账截图。

出现以下情况时，先停止提交信息或付款：

- 要求账号密码、邮箱密码或验证码；
- 收款主体、域名或订单查询方式无法核对；
- 未说明临时会话凭证的用途与处理方式；
- 没有写清覆盖、未交付、失败和已交付后的退款边界；
- 承诺账号不会被限制、模型全部立即开放或任何任务都不限量。

## 常见问题

### 没买过 Plus，可以直接买 Pro 吗？

可以直接比较 Pro 100 / 200，无需先买 Plus。官方另有 Pro 500，PlusGO 当前该档暂停。支持地区和账号规则仍需遵守，新购 Pro 200 不是旧 20×，轻量使用者可以继续选择 Plus。

<a id="pro-20-是不是不限量"></a>

### Pro 是不是不限量？

更高的使用档位仍可能遇到模型、功能或周期上限，不能理解成 Work / Codex 任务不限量。以 Usage 和实际功能提示为准。

<a id="5-买完不够用能补差价吗"></a>

### Pro 100 买完不够用，能补差价吗？

不能默认补差价。Pro 200 新订阅已恢复，先看官方变更确认页或第三方当前购买条件，确认金额、剩余价值与生效时间。先分清 Chat 限额与 Work / Codex 用量，换档不保证额度全满；旧 20× 资格与截止日另核对 [历史额度说明](./articles/pro-20x-pause-and-renewal.md#official-return)。

### 买 Pro 能马上看到 Astra 吗？

不能仅凭购买承诺。入口受账号、客户端、开放进度和工作区设置影响；订阅正常但未看到模型时，先核对这些条件。

### 微信支付和支付宝能直接在 ChatGPT 里用吗？

官方可用付款方式以实际结账页为准。第三方商品展示的支付宝 / 微信入口，不等于 OpenAI 官网支持相同付款方式。

### 付款后没生效或失败怎么办？

**退出前先确认购买账号的邮箱与登录方式**，收据邮箱可能不同；Apple 隐藏邮箱账号用原 Apple 账号的“继续使用 Apple”。确认后再重新登录，App 内购可按 App 的 Restore purchases 同步。仍异常时保存脱敏记录、查询原订单并联系对应渠道，不反复下单或公开凭据。[官方排查顺序](https://help.openai.com/en/articles/6950777-what-is-chatgpt-plus)。

<a id="20-已安排续订到期时间没变是失败了吗"></a>

### 历史 20× 订单已安排续订，到期时间没变，是失败了吗？

不一定。这是历史正常续订订单的到期扣费安排，成功后才延长周期；欠费续费和恢复按原核验说明验收。旧续订商品当前隐藏，原订单继续查询；周期接续不保证 10 月 29 日后仍有旧额度。按 [历史订单排查](./articles/pro-20x-pause-and-renewal.md) 联系原渠道，不重复下单。

### 公司多人使用 Pro，可以统一付款吗？

可以沟通个人账号统一采购；套餐数量、合同、对公付款与发票安排需在付款前确认。每位员工使用自己的账号，需要组织管理时再比较 Business。

## 最后建议

先判断任务和用量，再核对费用、账号与换档条件。需求明确的重度用户可以直接比较 Pro；公司付款的先完成采购确认。开通后分别检查订阅有效期、可用模型和 Usage，才能确认自己得到的是需要的方案。

产品、价格、额度和第三方条款都可能变化，以账号、结账页及本次采购约定为准。
