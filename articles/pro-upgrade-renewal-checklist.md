# 已有 Plus / Pro，换档与续费前要核对什么？

> 最近核对：2026 年 9 月 12 日

已有订阅时，我不会只问“能不能开通 Pro”，还会确认这次付款改变什么：套餐档位、有效期、后续扣款，还是额外可用量。它们可能有不同的生效规则，不能只看付款成功。

> **20× 特别提醒：** 自 9 月 10 日起暂停新订阅与升级；有效老用户可续费，取消／降级生效后不能在暂停期间买回。先读 [20× 资格与续订说明](./pro-20x-pause-and-renewal.md)，不要照旧按“先取消再重买”操作。

## 一、先留下当前状态

以下内容保存在自己的设备上，不要贴进公开 Issue。页面没有显示的项目写“待确认”，不要按套餐名称推算。

| 核对项 | 自己填写 |
|---|---|
| 当前套餐与目标档位 | 待填写 |
| 当前订阅到期时间或下次扣款时间 | 待填写；两者不要混为一项 |
| 原购买渠道与订阅管理入口 | 待填写 |
| 本次完整费用、币种和购买周期 | 待填写 |
| 剩余时长或已付款金额如何处理 | 待确认 |
| 当前用量与各窗口重置时间 | 待填写 |
| 是否有尚未确认结果的付款或订单 | 待核对；有则先处理原记录 |

用量可在 [Usage](https://chatgpt.com/codex/settings/usage) 查询。它用于看限额与重置，不能代替账单或订阅管理页。[用量查询说明](https://learn.chatgpt.com/docs/pricing#where-can-i-see-my-current-usage-limits)

## 二、按购买渠道核对，不套用别人的换档结果

### 在 OpenAI 账号内变更订阅

先看自己的变更确认页：本次收取多少、何时生效、下一次扣款是什么时间，以及原订阅剩余价值如何处理。没有看清最终确认项时，先不要付款。

目前 Free、Go、Plus 与 Pro 5× 不能升级至 20×。已有 20× 的取消或降级若尚未生效，可在当前周期结束前核对撤销选项；续费扣款失败则查看 OpenAI 邮件或原应用商店的恢复指引，不保证最终能恢复。[官方 Pro 暂停说明](https://help.openai.com/en/articles/9793128-about-chatgpt-pro-plans)。

别人账号里的补差、优惠、立即生效或下周期生效提示，不是自己这笔购买的保证。无法确认时，通过 OpenAI 的支持入口询问，再决定是否继续。

### 原订阅由应用商店管理

先进入原商店的订阅管理页，核对当前订阅、后续扣款及取消状态。不要把另一个渠道的新订单当作原自动续费已经取消，也不要直接把网页订阅的处理方式套到商店订阅。

### 通过第三方购买

我会要求先确认本次商品的档位、账号适用条件、周期和异常处理，再决定是否购买。第三方人民币报价、换档和售后条件，与 OpenAI 账号内的订阅变更分开看。

以 PlusGO 当前的 Pro 月付商品为例：

- Pro 20× 暂停新购与升级，不能通过补差价或支付全价开通；有效老用户需要先核验续订资格。
- Pro 5× 覆盖开通后按新套餐重新计算 1 个月，不叠加原订阅剩余时间；确认开通前看清页面提示。
- 有效 Pro 20× 续订保留剩余时间，到期扣费成功后从原到期日接续 1 个月；“续订安排已完成”不表示到期日已立刻延长。
- Codex 额度可能只补足新旧套餐差额，也可能重置；不能承诺覆盖后一定全满。

20× 暂停新购／升级来自 OpenAI；付款前核验、覆盖与到期续订流程则是 PlusGO 的商品条件，不能套到所有购买渠道。购买入口及商业披露见 [主指南的换档提醒与报价入口](../README.md#upgrade)；最终仍需核对本次订单。PlusGO 与 OpenAI 无隶属或授权关系。

## 三、把“换档费用”和“用量变化”分开问

我会在付款前确认下面四句话能否得到明确答复：

1. 这次买的是哪个档位，费用是完整购买价还是变更费用？
2. 新周期从何时开始，原订阅剩余时间如何处理？
3. 原购买渠道还有没有后续扣款，需要在哪里管理？
4. 开通后的订阅状态、可用量和重置时间应分别在哪里验收？

“套餐已升级”不应直接推导为“所有用量已经重新充满”。Pro 的标称用量、单项功能限制与当前窗口状态需要分别核对。[套餐与用量边界](https://learn.chatgpt.com/docs/pricing#what-are-the-usage-limits-for-my-plan)

如果购买目的是解决额度不足，先用 [一周记录表](./pro-usage-journal.md) 确认是真正的持续需求，还是某一次赶工；订阅期限、额外点数与重置也不要混成一笔权益。

## 四、付款后的验收顺序

- [ ] 购买记录中的目标账号与实际登录账号一致。
- [ ] 显示的套餐与所买档位一致；仅有“Pro”名称、无法确认具体档位时继续核对购买记录与账号信息。
- [ ] 生效时间、有效期或下次扣款时间与本次确认内容一致。
- [ ] 若为 PlusGO 20× 续订，已区分安排完成与到期扣费成功；需调整账单设置时先联系原渠道。
- [ ] Usage 中的可用量与重置时间已单独检查。
- [ ] 原订阅的后续扣款安排已在原渠道核对。
- [ ] 模型或功能入口仍有问题时，继续按 [开通后排查](../troubleshooting/pro-access-and-usage.md) 检查。

付款结果不确定，或页面状态互相矛盾时，先查询原订单并联系对应支持方，不要反复购买。只向确认过的官方支持或原购买渠道提供必要材料，不提交密码、验证码或完整会话凭据；公开文档纠错不需要订单详情。

公司统一付款的，先沿用 [企业采购清单](https://github.com/duck-gogo/chatgpt-plus-tutorial/blob/main/articles/chatgpt-enterprise-procurement.md) 确认账号数量、周期和采购要求，不要先垫付再补问手续。
